ทั้ง 4 แบบใช้ theme Warm Slate เดิมของเว็บ ฟอนต์ Noto Sans Thai และข้อมูลสินค้า/ราคาจริงจากระบบ — ต่างกันที่โครงสร้างหน้า ไม่ใช่สี header / เมนูรอง / footer เป็นแบบที่อนุมัติแล้ว (วาดย่อให้เห็นบริบท) ตัวแปรคือเนื้อหน้าระหว่าง header กับ footer

หมายเหตุกลาง (อ่านก่อนเลือก)
  • ข้อมูลสินค้า ราคาเริ่มต้น ราคาเต็ม ภูมิภาค และจำนวนแพ็กเกจ = ของจริงจาก API ณ วันที่ 9 ก.ย. 2026 (สินค้ายอดนิยม 8 รายการ) — ยอดขายทุกสินค้ายังเป็น 0 จริง จึงไม่มี mockup ใดวาดตัวเลขยอดขาย
  • ป้าย "−3%" ในแบบ D คำนวณจากราคาจริง (displayPrice เทียบ originPrice) — สินค้าที่ไม่มีราคาเต็มจะไม่มีป้าย
  • แบบ B นำ copy "วิธีเติม" 3 ขั้นที่มีอยู่แล้วในระบบกลับมาใช้ — ไม่มีการแต่งข้อความใหม่ที่อ้างสิทธิ์เกินจริง
  • สถานะ loading / error / หน้าเปล่าของชั้นสินค้า ใช้แพทเทิร์นเดิมที่มีอยู่ (skeleton + ลองใหม่) — ไม่ได้วาดในเฟรม
  • ทุกปุ่ม/ลิงก์ในเฟรมเป็นตัวอย่าง ไม่นำทางจริง
